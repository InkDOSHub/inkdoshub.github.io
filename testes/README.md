# Performance tests

- `windows/teste-desempenho.bat`: memory and CPU of the home screen and 7 open apps in Edge, WebView2, Brave and Electron.
- `windows/teste-arquivos.bat`: downloads the test files to `Downloads\InkDOSHub-arquivos-teste\` and opens each one in its app in each engine. Measures the time to open the app and the file, memory, CPU and the time to close. Report in `Desktop\InkDOSHub-teste\relatorio-arquivos.txt`.

The files (simple, medium and complex: PDF, DOCX, XLSX, PPTX, TXT, EPUB, JPG, MP4, MP3, JS and Excalidraw) are generated by `tools/gerar_arquivos_teste.py`. The `arquivos-teste` action publishes them to the `arquivos-teste` release with `lista.txt` (level, SHA-256, name). They stay out of git so the clone does not grow. To change the files, edit the generator; the action runs on push.
