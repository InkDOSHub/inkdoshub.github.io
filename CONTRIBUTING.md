# Contributing to InkDOS Hub

Thanks for helping. By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

## Ways to contribute

- **Bug:** use the [bug report form](https://github.com/InkDOSHub/inkdoshub.github.io/issues/new?template=bug_report.yml).
- **Idea:** use the [feature request form](https://github.com/InkDOSHub/inkdoshub.github.io/issues/new?template=feature_request.yml).
- **Translations:** language packs are `idiomas/<code>.json`; `python3 tools/idiomas_textos.py` lists missing strings. New interface text is written in English (see `assets/idioma.js`).
- **Security:** report privately, see [SECURITY.md](SECURITY.md).

Never attach real files, screenshots or private filenames; use synthetic examples.

## Running locally

No build step for the site:

```bash
git clone https://github.com/InkDOSHub/inkdoshub.github.io.git
cd inkdoshub.github.io
python3 -m http.server 8000   # open http://127.0.0.1:8000/
```

- Vendored tools are rebuilt from pinned versions with `tools/build_apps.sh`; the copies in `inkdos/` and `visualizadores/` (`artcraft/` comes from `artcraft.yml`) are now maintained here (their origin is in each `UPSTREAM-SOURCE.txt`).
- The offline file list (`inicio/manifesto.json`) is generated by `tools/portal_manifesto.py` (the `manifesto-offline` workflow runs it on `main`).

## Pull requests

1. Branch from `main`; keep one tool (one folder) per pull request.
2. Make the smallest change that fixes the problem; do not refactor unrelated code.
3. Test it in Safari on iPhone/iPad when the change touches the interface.
4. Fill in the pull request template.
