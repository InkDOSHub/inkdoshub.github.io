Welcome to InkTerminal!
This is a real Alpine Linux (kernel 6.6) emulated in WebAssembly.

- Install programs with: apk add python3 git nano
- The ~/files folder exchanges files with this device (Upload and Download buttons).
- Tap Save to keep everything on this device.
- Session > Save to file stores the package list and the home folder
  in a password-protected file, so you can reinstall everything elsewhere.
