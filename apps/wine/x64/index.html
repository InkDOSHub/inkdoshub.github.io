i

A 64-bit x86 PC (x86_64) emulated by QEMU Wasm (open source, github.com/ktock/qemu-wasm): the x86-64 code is translated to WebAssembly while it runs. Inside: Alpine Linux with Wine 9 (64-bit) and the same desktop as x32. It is much slower than x32 and takes a few minutes to start.

Single core by default. Multi-core may not work, depending on the browser: it needs WebAssembly threads and shared memory, and Safari/WebKit (also in XeOS) runs them slowly.

Tap to click; "Right click" makes the next tap a right click; "Keyboard" opens the keyboard. First start downloads the machine (about 300 MB). Nothing is saved yet: the machine starts clean each time. No network yet.
