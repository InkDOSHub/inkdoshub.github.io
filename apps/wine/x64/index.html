Wine x64 (experimental)
i

A 64-bit x86 PC (x86_64) with Alpine Linux, emulated by QEMU Wasm (open source, github.com/ktock/qemu-wasm): the x86-64 code is translated to WebAssembly while it runs. This first stage is a text console; the graphical desktop and 64-bit Windows programs come next. It is much slower than x32. Single core by default; multi-core may not work, depending on the browser (it needs WebAssembly threads and shared memory, and Safari/WebKit runs them slowly). First start downloads about 140 MB. Log in as root. No network yet.
