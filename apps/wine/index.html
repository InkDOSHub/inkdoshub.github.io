i

Runs 32-bit Windows programs (98/XP era) with Wine inside the browser, using Boxedwine (open source, GPL). Nothing is installed: open a program as a .zip (or a single .exe) and pick the .exe to run. Your files appear as drive D:. First start downloads about 50 MB. Faster on the isolated address. Source: github.com/danoon2/Boxedwine.
