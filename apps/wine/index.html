Startup

Applies from the next start (Restart Windows).

Fewer services make Windows start faster. Turn on what a program needs.

Code cache: use Windows and your program for a while, then tap Save cache. The next starts load the translated code instead of translating it again. The cache can be moved to another device as a .boxedwine file (single-core and multi-core caches are separate).

i

Experimental. Light programs work best; heavy programs and games may be slow or not run, especially on x64.

Windows (Wine 11) running inside the page with Boxedwine (open source, GPL). The x86 code is translated to WebAssembly while it runs (JIT).

Multi-core (⚙) is off by default and should stay off on iPad and iPhone: Safari/WebKit (and XeOS, which uses it) runs the multi-core engine about 60 times slower, and Wine itself barely uses more than one core. One core reached 5,171 MIPS in XeOS on an iPad (A16).

Open file: pick a 32-bit program (.exe) or a .zip from Files. It is copied to drive D: (a .zip becomes a folder) without restarting Windows; open it in the file manager. Drive D: and what you install stay saved in this browser. 64-bit programs run in InkSoC (x64 option): console programs for now. Memory: up to 3 GB. Internet goes through the Hub tunnel.
