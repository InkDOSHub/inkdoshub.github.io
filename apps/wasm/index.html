InkDOS Hub Wasm Build
i

Compiles an open-source project to WebAssembly with Emscripten, on GitHub's computers, using your own GitHub account. The Hub creates a public repository named "inkdoshub-wasm-build" in your account with one build workflow; each build runs there (free for public repositories, up to 6 hours per build), so small and large projects work. Paste the project's git link and its build commands; when the build ends, the .wasm files (with their .js loaders) come back here, and "Run" opens a program in a text terminal (output and typing, no pop-ups). Your token stays only on this device; files from GitHub pass through the Hub's Cloudflare worker only because GitHub's download links block browsers. Only build code you trust: the commands run with your token's repository access inside the build.

GitHub account

Create a token with the "repo" and "workflow" permissions (open GitHub), then paste it here.
