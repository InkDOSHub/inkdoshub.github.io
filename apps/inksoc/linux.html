< InkDOS HubLinux
A Linux shell (BusyBox 1.35, static x86-64) running on InkSoC, our own engine: the x86-64 CPU and JIT are the same ones that run Windows programs, and Linux system calls are answered in WebAssembly. Files live in memory while the page is open (/root is home; ⇡ adds files there, ⇣ downloads one). Experimental: static programs only for now (no shared libraries, no network). BusyBox is GPL-2.0: source at busybox.net.
