InkDOS Hub XeOS tests
i

Full tests checks what this browser (XeOS) can do: storage, files, media, pop-ups and other APIs. "Run all tests" runs every test in a row (about 12 minutes, memory limit last); every result is saved in the browser, so nothing is lost if the page reloads; "Stop" ends the test that is running and keeps the results so far. Tests that need a tap, may reload the page or need a second window stay as buttons below. "Download report" saves a numbered JSON file; "Upload to GitHub" opens the results folder, where you drop the file and click "Commit changes".

Benchmark scores the browser like Geekbench (1000 = reference device). "Save PDF" keeps the charts and the data; on another platform, "Load PDF to compare" and "Save comparison PDF". If something fails, "Download log" and send the file.

Measures the browser on this device: CPU single and multi-core, memory, storage, JIT and WebAssembly, network, graphics, GPU and video encoding (~1–2 minutes, keep the page open). Save the PDF on each platform, then load the other PDFs here to make a comparison PDF.
