InkDOS Hub Zip
i

Opens and creates compressed archives with 7-Zip, on this device. Opens .zip, .rar, .7z, .tar, .gz, .bz2, .xz, .tgz and many others (iso, cab, dmg, arj, lzh, wim...). Creates .zip, .7z, .tar and .tar.xz, with an optional password for .zip and .7z. RAR files can only be opened: the RAR format is proprietary and only WinRAR can create it. Files are processed on the device's disk, a piece at a time, so large archives work too. 7-Zip is free software (LGPL and unRAR license).
