InkDOS Hub Terminal commands
i

Finder-style jobs for any terminal, or a-Shell on iPhone and iPad. Each command downloads a small open source Python script from this site and runs it on your device: nothing is uploaded. Files are read in 1 MB blocks, so big folders work too. Every command writes a log in the folder.

Needs Python 3. a-Shell, Linux and macOS usually have it. On Windows, install it once from python.org; if "python3" doesn't work there, change it to "python".

Folder

Paste into your terminal, or into a-Shell on iPhone/iPad. On a computer, paste the folder's path here. Leave it empty and every command asks for the folder when it runs (a-Shell opens the Apple menu; a terminal lets you drag the folder in).
