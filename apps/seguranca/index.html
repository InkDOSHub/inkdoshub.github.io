InkDOS Hub Security

All InkDOS Hub security tools in one place. The PDF tools run on this device and no file is uploaded. The Windows, Linux and macOS tools are terminal commands that check whole folders or drives; each one handles one file type, so scans stay small, and several can run at once in separate windows.

Windows

Open PowerShell, paste one line and press Enter. Only files of that type are opened, so OneDrive and iCloud online-only files of other types (like videos) are not downloaded. Several can run at once in separate windows.

PDF cleanNeutralizes JavaScript, auto-run actions, program launch and embedded files in every PDF. Output copy or R = in place.
irm "https://hub.inkdos.workers.dev/apps/editar-pdf/native/pdfclean.ps1?$(Get-Random)" | iex
Office cleanWord, Excel and PowerPoint (docx, xlsx, pptx and macro versions): removes macros, blanks external links (remote templates, linked files) and empties embedded objects. Old .doc/.xls/.ppt with macros are only reported. Output copy or R = in place.
irm "https://hub.inkdos.workers.dev/apps/seguranca/native/officeclean.ps1?$(Get-Random)" | iex
Archive scan.zip (and .rar/.7z when 7-Zip is installed): reports programs, scripts, shortcuts, disk images and fake extensions (like .pdf.exe) inside. Report only.
irm "https://hub.inkdos.workers.dev/apps/seguranca/native/archivescan.ps1?$(Get-Random)" | iex
Risky files scanLoose .exe, .lnk, .js, .vbs, .bat, .hta and similar files and fake extensions in document folders. Nothing is opened or downloaded. Report only.
irm "https://hub.inkdos.workers.dev/apps/seguranca/native/riskyfiles.ps1?$(Get-Random)" | iex
Linux

Open Terminal, paste one line and press Enter. Needs python3 (already there on most systems). PDF clean needs qpdf: sudo apt install qpdf (or dnf/pacman). Only files of that type are opened; several terminals can run at once.

PDF cleanNeutralizes JavaScript, auto-run actions, program launch and embedded files in every PDF. Output copy or R = in place.
curl -fsSL "https://hub.inkdos.workers.dev/apps/seguranca/native/pdfclean.sh?$RANDOM" | bash
