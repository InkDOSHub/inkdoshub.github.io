Windows app, without OBS

i

A small open source app that creates the camera "InkDOS Hub Webcam" on Windows 10 or 11 (64-bit). You only choose the quality.

  1. Extract the ZIP and open "InkDOS Hub Webcam.exe". If SmartScreen warns, click "More info" › "Run anyway" (the app is not signed).
  2. The first time, allow administrator permission once, to create the camera.
  3. Choose the quality, scan the QR code with the iPhone and tap Start.
  4. In Zoom, Teams or Meet, choose the camera "InkDOS Hub Webcam". Keep the app open during the call.

Source code: windows/webcam, with the virtual camera from softcam (MIT).

With OBS Studio (supported path)

i

iPhone (Safari, Host) → Wi-Fi (WebRTC) → PC (Guest page) → OBS Studio → OBS Virtual Camera → Zoom, Teams, Meet…

This flow was designed around this path, which is the supported one: Windows 10 or 11 with OBS Studio, using the OBS Virtual Camera as the Windows webcam. OBS on macOS and Linux works the same way. Other paths also work, such as a Window capture of this page in OBS, or any program that can turn a browser window into a virtual camera.

1. Install OBS Studio (once)

  1. Download OBS Studio from the official website: obsproject.com/download. It is free and open source.
  2. Install it and open it. If the setup wizard appears, choose "Optimize just for using the virtual camera".
  3. In Settings › Video, set Base and Output resolution to 1920x1080 and FPS to 60 (or 3840x2160 for 4K).

2. Add the iPhone image to OBS (once)

  1. On the PC, tap Guest on this page. Under the QR code, open "Link for OBS" and tap Copy. Then close this tab: the same code works in one window at a time.
  2. In OBS, under Sources, click + › Browser › OK. Paste the link in URL, set Width 1920 and Height 1080 (or 3840 and 2160), tick "Use custom frame rate" and choose 60.
  3. Untick "Shutdown source when not visible" and click OK. Right-click the source › Transform › Fit to screen.
  4. The QR code now shows inside OBS. OBS keeps the same code, so next time you only need to open OBS.

3. Start the camera

  1. On the iPhone, scan the QR code with the Camera app (or open this page, tap Host and type the code). Choose the quality and tap Start. Hold the iPhone horizontally.
  2. In OBS, click Start Virtual Camera (Controls panel, bottom right).

4. Use it as the Windows webcam

  1. Zoom: Settings › Video › Camera › choose "OBS Virtual Camera" and tick HD. Untick "Mirror my video" if you want the image as others see it.
  2. Teams, Google Meet (Chrome or Edge), Discord and most apps: choose "OBS Virtual Camera" in the camera settings.
  3. If no app sees any camera: Windows Settings › Privacy & security › Camera, turn on "Camera access" and "Let desktop apps access your camera".
  4. The Windows Camera app and Settings › Cameras may not list the OBS Virtual Camera. That is normal; Zoom and the other apps still see it.

Tips

  • Both devices should be on the same Wi-Fi, preferably 5 GHz. The pairing uses the free public PeerJS server; the video goes directly between the two devices and is not uploaded.
  • Keep Safari open on the iPhone with the screen on. If you switch apps, iOS turns the camera off; it comes back when you return to Safari.
  • Zoom sends at most 1080p, so 1080p 60 fps is the best choice for calls. 4K is useful for recording in OBS.
  • Tap Details on the PC to see the resolution, frame rate, codec and delay that are really arriving.
