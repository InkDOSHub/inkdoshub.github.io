Terminal Desktop
i

System. Alpine Linux 3.22 for x86 (32-bit), running in the page with v86 (open source, BSD), the same engine as the Linux terminal: the x86 code is translated to WebAssembly while it runs. Alpine was chosen because it is small (musl and BusyBox), fast to start and has a large package collection for 32-bit x86, which most other distributions dropped.

Desktop. Xfce with the Arc theme and Papirus icons, all ready-made Alpine packages. Xfce was chosen because it is a complete, polished desktop (menu, taskbar, file manager, settings) that is still light enough for an emulated 32-bit processor; GNOME, KDE and Cinnamon need a graphics card and would be too slow here.

Programs. Install with apk add name. Repositories: Alpine main and community (in /etc/apk/repositories; testing can be added). Inside, pip (Python), npm (Node.js), git and gcc also work for their own packages. Only 32-bit programs run.

Internet. Through the Hub tunnel on Cloudflare: TCP only (web, git, apk, ssh). No UDP or ping, no e-mail sending (port 25), and no incoming connections. Modern sites in a browser inside Linux are too slow to be practical.

Memory and files. 1 GB of RAM, compressed memory (zram) and a 2 GB swap disk in the site storage. The system disk (3 GB) is downloaded once and keeps what you install. Open file copies to /root/Device. Built by GitHub Actions: tools/linux-gui.
