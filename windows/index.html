InkDOS Hub for Windows

  • InkDOS Hub for Windows (installer, no admin) — the same apps as the website, each in its own window. Apps are saved on the PC when you check them in ☰ › Offline (every file checked by SHA-256), so they open without internet. No telemetry. Also as a portable .zip.

Built from the public source code of this project by GitHub Actions (repository, MIT license).

Verify the download

The programs are not code-signed, so Windows SmartScreen may warn on first run ("More info" → "Run anyway"). To check the file is intact, run in PowerShell Get-FileHash .\FILE and compare with the SHA-256 above.

Privacy

InkDOS Hub does not collect, store or send personal data. There are no accounts, no analytics and no ads. Files stay on your device. The Webcam and Transfer apps only connect directly to the devices you pair yourself. Optional tools are downloaded only from each project's official source, when you ask for them.
