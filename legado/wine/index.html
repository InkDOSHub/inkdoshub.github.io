Windows programs

Wine runs Windows programs inside the page, on a desktop of its own. Everything stays on this device: drive C: holds what you install and drive D: holds your files.

  • To install, tap Install program and choose an .exe, .msi or .zip file. Opening an .exe from XeOS also brings the file here.
  • Installed programs appear as icons on the desktop. One tap opens them.
  • Only 32-bit (x86) programs work. Older programs work best.
  • The Session button (while Wine is open) saves the installed programs and drive D: to a password-protected file. Open session brings everything back, even after the site data is cleared.
  • The first start downloads about 220 MB and spends a few minutes setting up Windows. After that it is much faster.
